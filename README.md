# CHaser ステージエディタ

CHaser の Blockly チュートリアル用ステージを作るためのエディタです。
マップを描くと、その場で模範解答プログラムが動き、何手でクリアできるか（またはどこで止まるか）が盤面に出ます。

公開ページ：https://moyac1012.github.io/chaiser-stage-editor/

## できること

- ステージ一覧：検索、グループの開閉、ドラッグでの並べ替え（グループをまたいでも可）、複製・削除、グループの追加・名前変更
- 盤面：6種類のマスを塗る（数字キー 1〜6 で切り替え）、大きさの変更、ASCII での直接編集、複数マップ
- 模範解答：ステージのブロックセットに合わせた Blockly、実行・1手ずつ進める・途中の手に戻る、失敗の理由と場所の表示
- HOT の行動プログラム：Blockly で HOT の動きを作り、実行確認で COOL の 1 手ごとに HOT も 1 回動かす（「HOTを倒す、または N ターン後にアイテム数で上回る」条件にも対応）
- 設定：タイトル、グループ、ブロックセット、難易度（1〜15）、クリア条件、学習目標、反応型ルール、模範解答の画像
- ブロックセットの編集（「その他」→「ブロックセットを編集」）：セットの追加・名前変更・削除・並べ替え、使えるブロックの選択
- レビュー用 HTML の書き出し（「その他」→「レビュー用HTMLを書き出す」）：公開の対象にしたステージを 1 ファイルの一覧ページにする
- 元に戻す／やり直す（Ctrl+Z ／ Ctrl+Shift+Z）
- 自動保存（ブラウザの IndexedDB）と、書き出していない変更の表示
- 書き出し前の確認（模範解答でクリアできない盤面、難易度の未設定、画像なし）

## データの形式

旧エディタ（`000_chaiser/docs/stage_editor_next.html`）と同じ version 2 形式の JSON を読み書きします。
知らないキーも捨てずに残すので、旧エディタやレビューページとの行き来ができます（`tests/stages.test.ts` で確認）。

初めて開いたとき、同じ `moyac1012.github.io` で旧エディタを使った作業データがブラウザにあれば、読み込むかどうかを選べます。

## 開発

```sh
npm ci
npm run dev      # 開発サーバー
npm test         # ルール・データ操作・既定ステージの模範解答のテスト
npm run build    # dist/ に出力（BASE_PATH で公開パスを指定）
```

`main` に push すると GitHub Actions がテストとビルドを行い、GitHub Pages に公開します
（リポジトリの Settings → Pages → Source を「GitHub Actions」にしておく）。

## 構成

| ディレクトリ | 役割 |
| --- | --- |
| `src/domain` | ステージデータの型、マップ・並び・クリア条件の純粋関数、読み込み時の正規化 |
| `src/engine` | ゲームルール（1手ずつの進行と勝敗判定）、プログラムの実行 |
| `src/blockly` | ブロック定義と JavaScript への変換、ツールボックス、画面上のワークスペース |
| `src/checks` | 模範解答の実行確認・書き出し前の確認（engine と blockly をつなぐ） |
| `src/store` | 元に戻す履歴、画面の状態、ブラウザへの保存 |
| `src/io` | ファイルの読み込み・書き出し、レビュー用 HTML |
| `src/ui` | 画面（Preact） |
